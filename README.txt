EarthyBlue - HTML5 + CSS3 version

Files:
- index.html: semantic HTML5 structure
- style.css: regular CSS, responsive layout, no Bootstrap or JavaScript

Images:
Create a folder named "images" beside index.html and put these files inside it:
- banner.jpg
- scr01.jpg
- scr02.jpg
- scr03.jpg
- scr04.jpg

If you have the original EarthyBlue template images, use those files with these exact names.
If your images have different names, update the src attributes in index.html.

Open index.html in a browser to preview the site.
This is a clean modern recreation of the main sections, not a pixel-perfect copy of every original template detail.
